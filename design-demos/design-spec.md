# 电子科技大学百合社 · 展示页设计约定

## 目标与边界

为「电子科技大学百合社」设计中文响应式单页，项目英文标记可使用 UESTC YURI CLUB。用户确认社团定位为百合文化兴趣社群，面向对百合动画、漫画、小说和同人创作感兴趣的校园同好。页面的首要目标是浏览活动与作品，不以招新转化为中心。整体应让人感到这里有共同的兴趣、有创作和交流的空间；既有同人文化的亲近感，又有认真编辑的视觉秩序，不能做成学校行政门户或商业 SaaS 模板。

用户明确说：「图片素材我会在后面增添. 你现在主要是设计页面, 然后保留图片占位」。因此所有图片、Logo、活动海报均保留经过设计的诚实占位，不联网取图、不生图、不假冒真实海报或学校标识。占位使用适合方向的纯色、细线、编号与小字号用途文字，而不是破损图片。可以用 HTML/CSS 排版和抽象几何装饰，但不手绘人物、花卉或插画代替真实素材。图片容器带固定比例与注释，后续替换为 img 后不改变布局。

## 统一内容

导航：活动 / 作品 / 关于。首屏社团名称完整出现，主标题「让喜欢，在这里相遇。」；引导语「关于她与她的故事，也关于每一个喜欢这些故事的我们。」；按钮「浏览作品」跳 #works，「看看活动」跳 #activities。辅助介绍：「电子科技大学百合社，属于百合文化爱好者的交流与创作空间。」

活动区标题「一起，把故事延续」。三个示例活动：①「放映室里的共鸣」— 百合动画交流，一起聊聊那些打动我们的角色与片段；②「把喜欢写进故事」— 同人创作交流，分享灵感、片段与创作中的小发现；③「翻开下一页」— 漫画与小说共读，交换书单，也交换不一样的理解。第一项为重点活动，另两项次要。全部标记「活动示例」，不编造日期、地点或报名。海报占位推荐 16:9。

作品区标题「喜欢，也可以成为作品」。共六个示例：插画「晴天，与你」/「窗边的片刻」；漫画「放学之后」/「两个人的日常」；文字「写给夏天的信」；社刊「花开时，我们相遇」。每条包含类型、标题与一句简短原创摘要，标记「示例作品」，不虚构作者、点赞与真实发布数据。文字作品允许直接呈现短摘录作为设计示例，其他展示封面占位。筛选：全部 / 插画 / 漫画 / 文字 / 社刊，使用真正 button，aria-pressed 指示选中，纯前端过滤，有 aria-live 结果通知与空列表提示。卡片不是详情链接，不制造不能使用的点击入口。

关于标题「因为同一种喜欢，相聚在这里。」正文「从一部动画、一页漫画，到一段写下的故事，我们希望给每一种喜欢留一个位置。在这里交流作品、分享灵感，也认识愿意倾听的同好。」这属于待确认的设计文案，不声称注册或官方认证。页脚保留「联系方式待补充」，设计稿页脚说明活动和作品为展示示例。不放假的群号或报名按钮。

## 三方向与交付

每版为完整、自包含 HTML/CSS/JS，可直接 file:// 打开，无 CDN 与外部依赖。1440×900 桌面首屏与 390×844 手机首屏为共同截图尺寸，也检查 768×1024。主内容宽度不超过 1320px；正文一般 16px、最低 14px，注释最低 12px；对比度至少 4.5:1。允许有轻量首屏入场与 hover，不做滚动劫持，prefers-reduced-motion 下关闭动画。窄屏菜单可打开、关闭，选择锚点后关闭，Escape 关闭，aria-expanded 准确；普通锚点导航即可，不使用 scrollIntoView。

三个方向必须采用不同结构。A「同好星图」：墨黑、奶油白、低饱和蓝的复古图录，巨型衬线标题、错落作品索引，用版式表现夜间翻阅图录，不把页面做成科技产品。B「社团创作刊」：参考 It's Nice That 的创作内容编辑方式，明亮黄绿色、醒目栏目、非对称网格，以杂志首页式高密度内容开场。C「花间来信」：借鉴 Pentagram 文学出版物编辑思路，纸白、深玫瑰色、中文衬线标题，跨页与信笺式排版，文字和封面相互映衬。三版内容一致，不相互复制布局。

这是三方向选择阶段，不替用户选择最终版。交付截图和预览后，用户选择再记录 direction-approved.md 并整合 Astro 首页。当前首页保留，预览统一在 /design-preview/index.html。样式与交互仅影响各自文档，不引入 React、后端、登录、投稿或详情页。
